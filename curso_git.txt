*Para clonar projeto*
No bash
git clone
cd e o nome da pasta
code . (abre no vscode) 

*Criando repositórios*
No bash
git init
git status

*Enviar repositório para o github*
cd "nome da pasta"
git init
git status
git add "nome do arquivo"
git commit -m "nome da mudança"
git status para conferir

*Criar branch master* 
git branch -M master
git remote add origin " URL origem da pasta"
git push -u origin master

*Verificar as modificações do projeto*
git status depois das modificações
git add .
git commit -a -m "descrever a alteração"
git status
"Se quiser enviar um arquivo de vez, git commit "nome do arquivo" -m "Descrever alteração" 

*Enviando o código para o repositório*
git push

*Recebendo alterações* Atualizar o repositório
Sincronizar local com repositório remoto
git pull

*clonando repositórios*
copiar o link do https

*Removendo arquivos do repositório*
git rm (nome do arquivo que quer remover ex: c.txt)
git status
git commit para subir atualização
git push para subir
e depois para atualizar e usar de novo: git pull

*Verificando as alterações por meio de log*
git log (No terminal dentro do vs code)
